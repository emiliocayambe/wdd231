Site Plan: Chatsqui API Solutions

WDD 231 Individual Project Planning Document

1. Site Name

Proposed Name: Chatsqui API Solutions

Reasoning: The name is a fusion of "Chasqui"—the legendary messenger runners of the Andean Inca Empire known for their speed and reliability—and "API". It bridges local cultural heritage with modern cloud messaging infrastructure, representing fast, reliable communication for businesses migrating to Meta's official WhatsApp Business API using Chatwoot.

Optional Domain: chatsqui-api.com or chatsqui.ec

2. Site Purpose

The primary purpose of the website is to serve as an informational landing page and lead-generation portal for small and medium-sized enterprises (SMEs). It provides technical guidance, pricing tiers, and direct consultation booking to help business owners migrate from the standard WhatsApp Business mobile app to Meta's official WhatsApp Business Cloud API integrated with the open-source Chatwoot inbox platform.

3. Target Audience Scenarios

  • Scenario 1: "How can my sales team manage a single WhatsApp phone number across 5 agents simultaneously without getting blocked by Meta?"
  • Scenario 2: "What is the technical and financial difference between using the free WhatsApp Business app vs. migrating to the official Meta Cloud API with Chatwoot?"
  • Scenario 3: "Where can I request a live demo or technical assessment for migrating my existing customer contact history?"

4. Color Scheme

The color palette combines technical trust, brand visibility, and high contrast adhering to WCAG AA/AAA accessibility standards across light and dark viewports.

Navy Chasqui #0b2c56 Headers, Navigation & Footers
Teal WhatsApp #0d6e63 Links, Subheadings & Icons
Gold Chasqui #bca272 Buttons & Active States
Charcoal Text #222222 Main Body Text
Neutral Light #f8f9fa Page Background
